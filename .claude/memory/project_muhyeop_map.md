## 서비스 개요

무협맵은 협찬 리뷰어(블로거)들이 여러 플랫폼(레뷰, 리뷰노트, 미블, 강남맛집, 디너의여왕)의 협찬 위치를 네이버 지도에서 한눈에 보는 웹 서비스.

**핵심 사용 패턴 (원우씨 직접 제공):**
리뷰어는 "내 위치 기준"이 아니라 **"협찬 당첨 위치 기준"** 으로 주변 협찬을 찾음.
예: 강남 협찬 하나 당첨 → 무협맵에서 강남 검색 → 주변 협찬 몇 개 더 신청 → 하루에 3~4곳 묶어서 방문.
→ 핵심 가치 = **동선 최적화 / 루트 묶기**. 기존 리스트 앱으로는 불가능한 것.

**Why:** 레뷰에는 지도 기능 있지만 다른 플랫폼엔 없음. 리뷰어들이 매번 네이버지도로 따로 확인하는 불편함에서 출발. 원우씨 본인 + 와이프도 리뷰어.

## 현재 구현 상태 (2026-06-09)

**데이터 구조:**
- Places (장소, 영구) + Campaigns (캠페인, 마감일 있음) 분리
- 최초 제보자(Founder, 장소 영구 표시) vs 캠페인 제보자(Reporter, 마감일까지) 구분
- 채널: `channels` 배열 (복수 선택 가능 — 블로그/클립/인스타그램)
- 데이터는 JS 메모리 저장 (새로고침 시 소실 → Firebase 때 해결)

**주요 기능:**
- 지도 핀 표시 (카테고리별 이모지 아이콘, 활성 캠페인 없으면 미노출)
- 마커 클러스터링
- 채널 필터 (전체/블로그/클립/인스타그램)
- 협찬 제보 모달 (2단계: 장소 → 캠페인 정보)
- 중복 장소 감지: 좌표 50m 반경 + 이름 정규화 비교
- 지역 검색 (Geocoding API)
- 사이드바 리스트 (지도 영역 기준 필터링 + 새로고침 버튼)
- 네이버지도 앱 연동 버튼 (매장 상세 보기)

**모바일 UX:**
- 헤더: 검색창 + 아이콘 버튼 2개 (＋제보, ℹ서비스소개) — 네이버/구글맵 스타일
- 하단 바텀시트 (모집중인협찬): 탭으로 열기, 스크롤 시 전체 확장
- 핀 클릭 시 바텀시트로 매장 정보 표시
- 스와이프 다운으로 닫기 (시트, 사이드바 모두)
- 현재위치 버튼 fixed 고정 (바텀시트에 덮힘)
- iOS Safari: 100dvh, font-size 16px(줌 방지)

## 핵심 결정사항 (논의 후 확정)

**신청하기 버튼 제거 (2026-06-09):**
- 이유: 플랫폼별 캠페인 URL이 로그인 필요하거나 홈으로만 연결되어 신뢰도 낮음
- 대안: 플랫폼명 표시 → 유저가 직접 해당 플랫폼에서 찾아가는 방식
- Phase 2에서 화이트리스트 도메인 검증 + 신고 기능 붙인 후 재도입 예정

**캠페인 링크 → 선택 항목으로 변경:**
- 링크 없이도 제보 가능
- 필수: 채널, 플랫폼, 협찬내용, 마감일

**채널 선택: 셀렉트박스 → 체크박스 복수 선택:**
- 블로그, 클립, 인스타그램 복수 선택 가능
- 데이터: `channel: "블로그+클립"` → `channels: ["블로그", "클립"]`
- 필터: 포함 여부(includes)로 변경, "블로그+클립" 필터칩 제거

## Phase 2 예정

- **Turso(libSQL) 연동**: 데이터 영구 저장. Vercel Serverless Functions 경유, 토큰은 Vercel 환경변수 보관. (Firebase 아님)
- **간편로그인**: 카카오/네이버/구글 소셜 로그인
- **신고 기능**: 잘못된 정보 신고, 일정 수 이상 신고 시 자동 비노출
- **화이트리스트**: 플랫폼 선택과 URL 도메인 일치 검증
- **장소명 검색 API**: 네이버 로컬 서치 (현재 주소만 가능)
- **동선 최적화**: 선택한 협찬들 경로 묶기 (핵심 가치 강화)
