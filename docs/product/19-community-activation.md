# 커뮤니티 활성화 전략 (북극성)

> 상태: **논의 중(2026-10-13 시작).** 방향·보상 모델은 합의, 유입/실행은 열린 항목. 이 문서는 대화에서 정리된 내용을 담고, 결정이 서면 구체 플랜으로 확장한다. 관련: [[02-roadmap]] Phase 3 전략노트, [[17-travel-pins]](커뮤니티 구현), [[10-growth-strategy]], [[06-decision-log]].

## 왜 — 북극성 = 커뮤니티 활성화
무협맵 사용은 본질적으로 **에피소딕**("체험단 필요할 때만")이라 그것만으론 재방문이 안 생긴다. **커뮤니티가 '협찬 없어도 올 이유'를 만들어 에피소딕 → 리커링으로 전환하는 유일한 축.** 커뮤니티가 살면 재방문·성장·제휴 레버가 따라오고, 죽으면 가끔 쓰는 검색툴로 남는다. → **커뮤니티 활성화가 서비스 방향을 잡는다**는 것이 사용자(운영자)의 판단.

리프레임: 무협맵 = "협찬 검색 도구"가 아니라 **"리뷰어 커뮤니티(협찬+후기를 지도로)"**.

## 보상 모델 = 블로그 방문자수(트래픽)
활성화의 핵심은 **후기 작성에 보상**이 있어야 한다는 것. 보상 통화는 **블로거의 블로그 방문자수(유입)**.
- **왜 정렬되나**: 체험단 유저의 **90%+가 네이버 블로거**(사용자 확인). 블로거가 진짜 최적화하는 KPI = 블로그 유입(→ C-rank↑ → 체험단 선정↑ + 애드포스트 수익). 돈/포인트 같은 인위적 보상보다 강하고, 공생(우리=콘텐츠, 리뷰어=트래픽).
- **작동 방식**: 후기 카드 = 블로그로 가는 입구(클릭 시 블로그 글 이동, `reviews.click_count` 추적 중). 보상 = **앱이 그 블로그로 보내는 클릭(방문)**.
- **키우는 2축**: ①후기 노출 극대화(지도 상세·피드·라이브버블·내지역 알림 등 전 접점) → 후기당 클릭↑. ②**보상 체감** — 작성자에게 "당신의 후기로 N명이 블로그 방문" 노출(click_count 가시화). *안 보이면 보상이 없는 것.*

## 활성화 루프
```
후기 씀 → (블로그 유입 + 커뮤니티 노출) → 남들이 보고 이웃추가/좋아요
  → "누가 널 이웃추가 / 좋아요 / 내 지역 새 후기" 알림(하루요약 엔진 재활용)
    → 돌아와서 또 씀 → 콘텐츠↑ → 유저↑ → 클릭↑ (복리)
```
후기 = 연료, 서이추(이웃) = 연결, 알림 = 복귀 트리거. 셋이 물려야 돈다.

## 대상·씨앗
- **대상(넓게)**: 네이버 체험단 블로거 전체(서이추는 카테고리 무관하게 C-rank에 유효 → 버티컬로 안 쪼개도 됨). 인스타/유튜브는 2순위.
- **씨앗/리치(현재)**: **무협맵 네이버 브랜드 블로그 + 그 블로그의 서이추 이웃 ~1500명**. 단 **무작위 서이추로 모은 weak tie**(이웃새글 피드로만 닿고 주목도 낮음) → 따뜻한 팬 아님, "리치 채널"로 봐야.
- **콜드스타트 재보정**: 1500은 교과서적 씨앗은 아님. 블로그 댓글/피드 홍보 전환율 통상 1~2%(과거) → 1500×1~2% = 15~30명. 단 "방문해주세요"(약함)가 아니라 **"후기 올리면 블로그 유입"(실익 훅)** 이면 전환이 더 높을 수 있음(가치 정렬).

## 핵심 통찰: 유입(획득)이 병목
**커뮤니티 활성화는 유입을 못 앞선다.** 보상 루프를 잘 깔아도 체험단 블로거가 앱에 꾸준히 안 들어오면 커뮤니티가 안 채워진다. 현재 Naver 유입구는 **무협맵 블로그 하나**라 얇음.
- **아이디어(블로그=보상 증폭기)**: 무협맵 블로그가 **"이주의 베스트 후기"를 소개**(후기 쓴 블로거 + 블로그 링크 노출) → 소개되면 무협맵 블로그(+1500 이웃 피드) 트래픽이 그 리뷰어 블로그로 쏨 → "후기 잘 쓰면 소개돼 유입 생김" → 더 씀. **블로그(획득) ↔ 커뮤니티(후기) ↔ 보상(트래픽)** 한 바퀴로 물림.

## ❓ 열린 질문 (결정 필요)
1. **유입 채널 확장** — 블로그 하나로 충분한가? **체험단 카페·오픈채팅**(의도 높은 채널) 운영/진입 가능한가?
2. **블로그 SEO 유입 현황** — "지역별 협찬 모음" 글이 실제 체험단 블로거 검색 유입을 만드나?(어드민 일별 유입경로로 측정)
3. **베스트 후기 소개(보상 증폭기)** — 실제로 운영 가능한가?
4. **정체성** — "리뷰어끼리 밀어주는 실익 네트워크" vs "체험단 정보·후기 나누는 소통방" (강조점이 설계를 바꿈).

## 빠른 첫 레버 후보 (결정 후)
1. **"내 후기 성과" 가시화** — 내 후기/MY에 "이 후기로 블로그 N회 방문"(`click_count` 노출). **데이터 이미 있어 빠름 + 보상 체감 큼.** ← 데이터 쌓이는 동안 깔아두기 좋음.
2. **후기 노출 극대화** — 접점 확대.
3. **베스트 후기 블로그 소개** — 위 증폭기.
4. **복귀 알림** — 이웃추가/좋아요/내지역 새후기 푸시(하루요약 엔진 재활용).

## 공급 부트스트랩 이벤트 (계획, 회원 더 쌓인 뒤)
초기 후기 공급을 터주기 위한 단기 외적 보상 이벤트. 블로그 트래픽(본질적 보상)을 보완하는 킥스타트. (Phase2 런칭 후기 이벤트의 구체화 — [[06-decision-log]] 2026-10-03.)
- **상품(총 9만원, 스타벅스 쿠폰)**: **후기 수** 랭킹 — 1등 3만 / 2등 2만 / 3등 1만. + **좋아요 특별상**(좋아요 많이 받은 유저) 3만.
- **기간**: 2주.
- **시점**: **회원이 좀 더 쌓인 뒤** 시작(참여자 부족한 초기에 돌리면 효과 X — 유입 먼저).
- **설계 주의(품질 vs 수량)**: '후기 수' 랭킹은 **양 위주라 저품질/스팸 후기 리스크**(빨리 많이 올려 1등). 완화: 후기=네이버 블로그 URL+매장명 검증(이미 있음) 유지 + **최소 품질 바(또는 위너 수동검수)** + **좋아요 특별상으로 품질 축 균형**. 1인당 과다 등록 방지 고려.
- **ROI**: 9만원은 후기 공급+참여 킥 대비 저렴 — 플라이휠에 불붙으면 남는 장사.
- **법적 체크(소액이라 리스크 낮음, 변호사 의견 아님)**: ①경품규제=2016 경품고시 폐지로 소비자경품 한도 자유. ②세금=기타소득 **건별 5만원 이하 과세최저한** → 3만원 쿠폰은 원천징수·신고의무 없음(앞으로도 1인당 건별 5만원 미만 유지가 깔끔). ③**랭킹**(노력기반)이라 추첨(우연)과 달리 사행성 무관. ④**이벤트 약관 고지 필수**(기간·선정기준·상품·인원·발표·변경취소 + 쿠폰발송용 연락처 수집 동의). ⑤**뒷광고(표시광고 심사지침) 톤 주의**: 쿠폰은 "특정 매장 호평"이 아니라 "무협맵에 후기를 모아준 기여"에 대한 리워드(기준=후기 '수', 내용 중립)라 성격이 다름 → 공지를 '감사 리워드' 톤으로. ⑥어뷰징(허위/자가후기 랭킹조작)은 위너 수동검수로 방어.

## 측정
GNB **커뮤니티 탭 사용 비중**(`gnb_daily`, 2026-10-13 집계 시작) + 후기/서이추 작성률 + 후기당 평균 블로그 클릭(`click_count`) + 알림→복귀. **감이 아니라 데이터로 약한 고리를 집어** 깊게 판다.
