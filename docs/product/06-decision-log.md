# 의사결정 기록

## 2026-07

### 종료 매장도 검색으로 선택해 후기를 볼 수 있게 한다. (2026-07-10)

지도 검색에서 캠페인이 종료된 매장명을 검색하면 "현재 진행 중인 협찬이 없는 매장이에요" 알럿만 떴다. 매장은 삭제하지 않고 후기가 남으므로, 종료 매장도 **검색 시 상세를 열어(후기 탭 기본) 선택·후기 열람**이 가능하게 변경(알럿 제거). 활성 매장은 기존대로 핀 선택 + 캠페인 탭.

### 매장은 삭제하지 않는다.

캠페인이 종료되어도 매장은 유지한다.

### 후기는 네이버 블로그만 지원한다.

블로그 유입과 정보량을 고려한 결정.

### 플랫폼

리뷰노트 → 디너의여왕 → 강남맛집 우선.
