1. 플랫폼별 요약

#플랫폼운영사접근형태약관상 자동수집·영리이용 제한저작권·DB 귀속확인
1리뷰노트리뷰노트앱·웹(SPA)·로그인 제9조 금지행위: 회사 동의 없이 서비스 정보를 영리·비영리 목적 복제·제3자 제공 금지 / 매크로·어뷰징 부정이용 금지 / 지재권 침해 금지 제13조 서비스 저작권 회사 귀속, 제16조 콘텐츠 사용권 1년 🟢
2강남맛집체험(주)웹·로그인 상업행위 금지. 명시적 자동수집 금지 조항은 없음(리뷰노트·레뷰 대비 약함) 제19조: 체험 리뷰 저작권이 "회사"에 귀속(임의 삭제·변경 시 상품가 변제) 🟢
3디너의여왕디너의여왕웹(SSR)·robots 일부 허용 금지행위 (g) 회사 동의 없이 영리목적 서비스 이용, (c) 지재권 침해 + 업무방해 금지. 매크로 명문 조항은 없음 제13조 서비스 저작권 회사 귀속, 제16조 콘텐츠 영구 사용권 🟢
4레뷰(REVU)레뷰코퍼레이션웹·앱(SPA)·로그인 제9조 e항(리뷰노트와 동일 문구): 회사 동의 없이 서비스 정보 영리·비영리 복제·제3자 제공 금지. 플랫폼정책: 무단 수익링크·재판매 금지 제13조 서비스 저작권 회사 귀속, 제16조 보상 콘텐츠 사용권 🟢
5미블(mrblog)미블웹(SPA)·로그인 11조: 서비스로 얻은 정보를 개인 이용 외 복사·가공·번역 등 2차저작·복제·배포·제3자 제공 금지. 12조: 광고·상업행위 시 콘텐츠 삭제 2차저작 전면 금지(11조) 🟢
업계 공통 패턴 (실측) — 리뷰노트·레뷰는 사실상 동일한 약관 템플릿을 사용하며, 둘 다 제9조 e항 "회사 동의 없이 서비스 정보를 영리·비영리 목적으로 복제·제3자 제공 금지" + 매크로·부정이용 금지 + 제13조 서비스 저작권 회사 귀속을 명문화. 미블은 제11조 2차저작 전면 금지, 강남맛집은 제19조 리뷰 저작권 회사 귀속. 명시적 "크롤링 금지" 문구가 없어도 이 조항들로 사실상 커버된다.

1-1. 실측 조항 상세 (원문 확인 🟢)

플랫폼핵심 조항(원문 발췌)
리뷰노트제9조 금지행위: "회사의 동의 없이 서비스 정보를 변경하거나, 영리 또는 비영리 목적으로 정보를 복제·출판·방송 등에 사용하거나 제3자에게 제공하는 행위" / "해킹, 매크로·어뷰징 등 부정한 방법으로 서비스 이용" / 지재권 침해 금지. 제13조 서비스 저작권 회사 귀속, 제16조 콘텐츠 사용권 1년. 개인정보처리방침에 매장명·매장주소·사업자정보도 수집항목.
레뷰제9조 e항(리뷰노트와 동일 문구): "회사의 동의 없이 서비스 정보를… 영리 또는 비영리 목적으로 복제·제3자 제공 금지". 제13조 서비스 저작권 회사 귀속, 제16조 보상 콘텐츠 사용권. 플랫폼이용정책: '콘텐츠' 정의에 "회사가 복제한 게시물 포함", 무단 수익링크·재판매 금지.
강남맛집제19조: "체험하고 작성한 모든 형태의 리뷰는… 그 저작권은 회사에 귀속"(임의 삭제·변경 시 상품가 변제). 제12조 회사가 콘텐츠 사본 저장. 상업행위 금지. 명시적 자동수집 금지 조항은 없음.
미블제11조: "서비스를 이용하여 얻은 정보를 개인적 이용 외에 복사·가공·번역 등 2차적 저작을 통하여 복제·배포·제3자 제공하는 행위 금지". 제12조 상업행위 시 콘텐츠 삭제.
디너의여왕금지행위: "g. 회사의 동의 없이 영리를 목적으로 서비스를 이용하는 행위" / "c. 지적재산권 침해" / "d. 업무 방해". 제13조 서비스 저작권 회사 귀속, 제16조 콘텐츠 영구 사용권(복제·배포·2차저작). 개인정보 목적에 "서비스 부정이용 방지" 명시. robots 일부 허용·SSR로 5곳 중 유일하게 제한적 여지.

2. 플랫폼별 우리(무협맵) 리스크 & 대응

#플랫폼핵심 리스크무협맵 대응강도
1리뷰노트 제9조 e항 정면 저촉(서비스 정보 영리·비영리 복제·제3자 제공 금지) + 매크로 부정이용 금지 + 제13조 저작권 회사귀속. 로그인 SPA → 우회 시 정보통신망법 형사 공개영역 외 접근 금지. 자동수집 제외, 제보/제휴로만 높음
2강남맛집 리뷰 저작권 회사 귀속 → 리뷰 본문·이미지 복제 시 저작권 침해 리뷰 본문/이미지 미복제. 매장·협찬 "사실"만, 원문 링크백 중간
3디너의여왕 9조(g) 영리목적 무단이용·(c) 지재권. 대량요청 시 업무방해. 집계 서비스에 불리한 판례군 robots 범위 내 저빈도·사실필드·링크백·사람검수. 장기 제휴로 9조 동의 확보 중간
4레뷰 제9조 e항 정면 저촉(리뷰노트와 동일 문구) + 제13조 저작권 회사귀속. 로그인·SPA → 우회 시 정보통신망법 공개영역만. 자동수집 제외, 제휴 우선 높음
5미블 11조 2차저작 전면 금지가 명확 → 수집·재배포는 정면 위반. 로그인·SPA → 우회 시 형사 수집 대상에서 제외. 제보/제휴 경로만 높음

4. 종합 결론 & 권고

  1. 기술적으로 가능 ≠ 법적으로 안전. 집계형 서비스는 판례군이 불리 — "리스크 제거"가 아니라 "리스크 관리".
  2. 로그인 벽 플랫폼(리뷰노트·레뷰·미블)은 자동수집 대상에서 제외. 우회 시 정보통신망법 형사 — 하지 않는다.
  3. 저작권·2차저작 조항(강남맛집·미블 등) 때문에 리뷰 본문·이미지는 복제 금지. 무협맵은 매장·협찬 "사실 필드"만, 원문은 출처 링크백.
  4. 디너의여왕(SSR·robots 일부 허용) 정도만 제한적 여지 — robots 준수 + 저빈도 + 사실필드 + 링크백 + 사람검수. 9조(g)는 장기 제휴로 해소.
  5. 최우선 전략 = 제휴/허락. 무협맵이 신청자 트래픽을 플랫폼으로 보내주는 구조가 협상 카드. 그 전까지 데이터 원천은 커뮤니티 제보 + 내부용 URL 단건 자동입력 검수 툴 수준.
  6. 절대 하지 않는다: 전국 협찬을 매일 대량 무단 크롤링해 무협맵 DB를 만드는 것.

실무 체크리스트

  • 착수 전 대상 플랫폼 최신 약관·robots.txt 원문 재확인(변경 잦음)
  • 로그인/접근권한 우회 없음(공개영역만)
  • 이미지·리뷰 본문 미복제, 사실필드만 + 출처·링크백
  • 저빈도·병렬 제한(업무방해 방지)
  • 커뮤니티 제보 비중이 실제 다수 → 집계성 비중 최소화
  • 중요 판단 전 변호사 검토
