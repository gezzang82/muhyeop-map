# 경쟁사

## 콜라보매니저 (collabomanager.kr)

- 협찬 모음 + 협찬 스케줄 관리 + 수익 정산. 인플루언서 대상 통합 매니저 앱(2만+ 사용자 홍보).
- 리스트(피드) 형태로 여러 플랫폼 캠페인을 모아보기.

### 실측 조사 (2026-07-23) — "몇 개 플랫폼만 뜨는" 이유

콜라보매니저는 **두 종류의 목록을 분리 운영**한다:

1. **협찬 "모아보기" 피드**(`/collabo`) = 실제 캠페인 데이터를 끌어와 노출하는 곳
   - 카드에 붙은 출처 플랫폼 로고가 **아싸뷰(assaview)·가보자체험단(gaboja) 2곳뿐**.
   - **레뷰·디너의여왕·리뷰노트·미블 등 큰 플랫폼 캠페인은 이 피드에 안 뜬다.**
   - 카드에 "sponsored" 표기 → 공식/제휴 물량으로 보임.
2. **플랫폼 "바로가기" 목록**(`/more/platform-list`) = 단순 아웃바운드 링크
   - 아싸뷰·레뷰·강남맛집·리뷰노트·리뷰플레이스·디너의여왕·미블·서울오빠·가보자를 나열하지만, **데이터를 가져오는 게 아니라 각 사이트로 나가는 링크만** 제공.

**해석**: 캠페인 데이터를 실제 집계하는 건 **제휴한 소수 플랫폼만**, 나머지 큰 플랫폼은 **데이터 미집계 + 링크만**. 즉 "몇 개만 올라오는" 이유는 기술이 아니라 **무단 대량집계의 법적 리스크를 피하려는 설계**로 보인다. → [07-legal-review](07-legal-review.md)의 결론("제휴한 곳만 데이터, 나머지는 링크백")이 시장에서 실제로 검증되고 있는 셈.

## 포포몬 (popomon.com)

- 무료 인플루언서 체험단 협찬 "매칭" 플랫폼(광고주↔인플루언서 매칭). 집계형과는 결이 다름(자체 캠페인 매칭).

## 리뷰노마드 (앱) — 지도형 집계 (직접 경쟁, 2026-08-27 조사)

- 여러 체험단 플랫폼 캠페인을 통합 검색·관리하는 앱. **"지도에서 내 주변 캠페인" 탐색** = 무협맵과 포맷상 가장 직접 경쟁.
- 통합 플랫폼: 블로그원정대·체험담닷컴·클립뷰·클라우드리뷰·데일리뷰·똑똑체험단·파인앳플·리뷰진·리뷰조아·후기업·포포몬·가보자·체험뷰·아싸뷰·링블·티블 등 — **중소 플랫폼 위주**. 디너의여왕·레뷰·리뷰노트·미블 같은 최대형은 목록에 두드러지지 않음(콜라보매니저처럼 **큰 플랫폼은 피하는 경향**).
- 노출: 마감일·리뷰마감·등록방법(블로그/인스타/구매평/유튜브/클립)·지역(지도). 신청은 **원문 플랫폼으로 링크백**.
- 제휴/sponsored 명시 없음.

## 모아뷰 (moaview.co.kr) — 웹 집계, 가장 공격적 (2026-08-27 조사)

- 체험단 캠페인 모아보기 웹(필터·미리보기·매일 갱신). **큰 플랫폼 포함 ~15곳** 집계: 리뷰노트·강남맛집·**디너의여왕**·레뷰·미블·서울오빠·체험뷰·클라우드리뷰·리뷰플레이스·아싸뷰·티블·놀러와·링블·어디야 등.
- 노출: 매장명·**이미지(썸네일)**·협찬내역·주소·마감일·경쟁률·지원자수·모집수 → **이미지까지 복제**(무협맵 법무 기준 '이미지 미복제'보다 공격적).
- 링크백: 제목→원문 플랫폼, [매장]→네이버지도, [상품]→쇼핑몰.
- 제휴/sponsored 표기 없음. "본 사이트는 체험단 사이트와 무관" **면책 문구만**.

## 집계 방식 스펙트럼 (2026-08-27 종합)

| 서비스 | 최대형 플랫폼 집계 | 이미지 | 링크백 | 제휴/표기 | 포지션 |
|---|---|---|---|---|---|
| 콜라보매니저 | ✕ (제휴 소수만 데이터, 나머지 링크만) | – | ✓ | sponsored(제휴분) | 가장 보수적 |
| 리뷰노마드 | 대체로 회피(중소 위주) | ? | ✓ | 없음 | 중소+**지도** |
| 모아뷰 | ✓ (디너의여왕 등 포함) | ✓ | ✓ | 없음("무관" 면책) | 가장 공격적 |
| **무협맵(현재)** | 디너의여왕 한정·사실필드·재작성 지향 | ✕ | ✓ | – | 보수+지도+**매장중심** |

**시사점**
1. **집계 + 링크백 모델은 시장에서 이미 흔함** — 여러 서비스가 실행 중("남들도 한다"는 사실). 단 **강도 편차가 큼**.
2. **최대형 플랫폼(디너/레뷰/리뷰노트/미블) 취급이 갈림길**: 보수 서비스(콜라보매니저·리뷰노마드)는 **회피**, 공격 서비스(모아뷰)는 **이미지까지 포함**. 무협맵 법무 결론([07-legal-review](07-legal-review.md))은 보수 쪽 — 디너의여왕 한정·사실필드·이미지X·재작성·링크백.
3. **아무도 제휴/동의를 명시하지 않고 "무관" 면책만** → 대부분 **관리된 리스크(묵인)** 구간으로 보임. **합법 확증이 아니다**(잡코리아·야놀자 판례 리스크 상존, [07-legal-review](07-legal-review.md)).
4. 결론: **모아뷰만큼 공격적으로 갈 이유는 없다**(리스크만 큼). 현재 보수 노선(디너의여왕 한정·사실화·링크백·**협찬내역 재작성**) 유지 + 장기 **제휴**가 정답. 재작성은 이미 파이프라인에 있는 GPT로 자동화 가능([13-ai-automation](13-ai-automation.md)).

## 무협맵 차별점

- **지도 기반** — 대부분 리스트형. **리뷰노마드는 지도라 포맷은 겹치나**, 아래 매장 영속성·후기·제보 기반에서 갈림.
- **매장 중심** — 캠페인이 마감돼도 매장·후기는 남는 영구 데이터 (리뷰노마드 등 집계형은 캠페인 사라지면 끝).
- **후기**(네이버 블로그) 축적 → "협찬 경험" 허브.
- **리뷰어 제보**(커뮤니티 UGC) 기반 → 무단 대량집계 없이 데이터 확보(법적 방패).
- 제휴 협상 시 **"신청자를 지도로 플랫폼에 보내준다"**는 유입 채널 가치가 리스트형보다 매력적.
