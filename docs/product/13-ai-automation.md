# AI 자동화

## 가동 중 (2026-08) — 수집 오토파일럿 AI 게이트

디너의여왕 매일 자동수집 후, 승인 대기(`scraped_items`) 항목을 AI(OpenAI/GPT)가 검수해 **자동등록 여부를 판정**한다. 사람이 하던 승인 판단을 대체. 구현: `api/_ai.js`, 결정 [[06-decision-log]] 2026-08-21.

- **카테고리 분류·정합** — 협찬 내용 기준으로 카테고리가 맞는지 확인·교정
- **중복 검사(fuzzy)** — 이름이 살짝 다른 기존 매장과 같은 곳인지 판정(정확매칭 규칙이 놓친 근접 중복 보완)
- **내용 신뢰성 판단** — 광고·배송형·매장명 불명확 등은 걸러 사람 검수큐로
- **페일세이프(보수적)** — 키 없음·호출 실패·저신뢰(신뢰도<0.85)·중복의심이면 전부 approve=false → 사람 검수. **확신할 때만 자동등록**(오등록 0 우선)
- **호출 범위** — 신규매장 후보(`new_place`)에만. 기존매장 추가/갱신(`add_channel`/`renew`)·결정론적 경고(flags)는 규칙이 처리 → 비용/오류 최소

## 결정론적(규칙, AI토큰 0)으로 처리

AI 없이 코드 규칙이 처리하는 것 — 신뢰도·비용 면에서 이쪽이 기본:
- **주소→좌표** 서버 지오코딩(네이버 로컬 검색 재사용, 한국 범위 밖=실패→검수). `api/_geocode.js`
- 마감 지난 캠페인 스킵 · 파싱 경고(요일/카테고리/채널) 라우팅 · 활성 채널중복 제외(`classify`)
