## 확정된 결정
1. **IA: 8탭 → 6 네비** — 다크 LNB(좌측). 항목: 대시보드 / 매장·캠페인 등록 / 조회 / 신고 목록 / 회원 목록 / 이벤트 팝업
   - "조회" = 매장/캠페인 **서브탭**으로 통합(기존 캠페인목록+장소목록)
   - "매장·캠페인 등록" = 등록/엑셀 **서브탭**으로 통합(기존 등록+엑셀)
2. **전체 리스킨** — 다크 LNB + 흰 카드 + 브랜드 레드 액센트, 캐릭터 로고, 우상단 어드민 프로필/로그아웃 헤더
3. **조회 = 서버 사이드** 검색/필터/페이지네이션/다중선택 — 데이터 **수천 건+** 전제
   - 함수 12개 한도 → 새 엔드포인트 금지. `api/places.js`/`api/campaigns.js` **GET에 파라미터 추가**
   - 분기: 파라미터 없으면 기존처럼 **전체 배열**(공개 지도용 유지), 어드민 호출이면 `{ rows, total }`
   - 필터: 매장명(LIKE)/카테고리(=)/상태(노출·숨김)/제보자(LIKE). `LIMIT/OFFSET` + `COUNT(*)`
   - 검색은 "조회" 버튼/엔터 트리거(타이핑마다 호출 X)
4. **등록 폼 고급화** — 달력 date picker(현재 텍스트), 장소 검색 리스트
5. **로그인 3-state** — 비밀번호 입력전/입력/보기

- **Phase 1**: IA 재편 + 전체 리스킨(LNB/카드/헤더/버튼) + 신고/회원/이벤트 표 리스킨. (시각/구조 먼저 확정)
- **Phase 2**: 조회 서버 검색/필터/페이지네이션/다중선택 (`places.js`·`campaigns.js` 확장 + 조회 화면). 가장 무거움.
- **Phase 3**: 등록 폼 달력 컴포넌트 + 로그인 3-state.
