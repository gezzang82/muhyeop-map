# 지식재산권(IP) 전략 — 상표/특허 당장 할 것만

> 조사일 2026-10-02. 비용은 **2026년 한국 특허청(KIPO) 전자출원 기준**, 별도 표기 없으면 **변리사 없이 본인 직접 전자출원(특허로)** 기준. 금액은 변동 가능 → 출원 직전 [특허로 수수료표](https://www.patent.go.kr/smart/jsp/ka/menu/fee/main/FeeMain01.do)로 재확인.

## 결론 (TL;DR)
- **지금 당장 = 상표 출원.** 브랜드명 "무협맵"을 **직접 전자출원**하면 **당장 나가는 돈은 출원료뿐 = 1개 류 52,000원**(등록료 20만원대는 심사 통과 후 6~14개월 뒤). 선출원주의라 **남이 먼저 "무협맵"을 등록하면 우리가 못 쓰게 막힐 수 있어** 시급도가 유일하게 높음.
- **특허(BM특허)는 지금 보류 권장.** 지도+체험단 집계형 서비스는 **진보성 확보가 어렵고**(유사 선행서비스 다수), **비용이 큼(200~600만원·변리사 필수급)**, **이미 서비스 공개 중이라 신규성 리스크**까지 있음. 돈 대비 효용 낮음.
- **권장 즉시 실행안**: 상표 **35류(핵심) + 9류 또는 42류**, 문자상표 "무협맵" 직접 전자출원. **즉시 현금지출 약 5~10만원**(출원료), 등록까지 총 약 26~52만원(아래 표).

---

## 1. 상표 (지금 당장 ✅)

### 왜 상표가 1순위인가
- **선출원주의(first-to-file)**: 한국은 먼저 쓴 사람이 아니라 **먼저 출원한 사람**이 권리를 가짐. 서비스가 알려질수록 제3자(또는 경쟁 플랫폼)가 "무협맵"을 선점 출원할 위험이 커짐 → **브랜드가 뜨기 전에 깔고 가는 게 가장 싸고 확실**.
- **식별력**: "무협"(무협지 장르) + "맵"(지도) 조합은 체험단/협찬 서비스에 대해 **암시적·임의적**이라 식별력 문제 낮음(= 등록 가능성 양호). 단 **동일/유사 선등록 상표 유무는 반드시 사전 검색**(아래 0단계).

### 어떤 류(類)에 낼까 — 무협맵은 "체험단·협찬 중개 플랫폼"
상표는 45개 류 중 **쓸 상품/서비스**를 지정해 낸다. 무협맵의 본질(인플루언서↔매장 협찬 매칭/광고 중개 + 앱/플랫폼)에 맞는 핵심 3개:

| 우선 | 류 | 포함 범위 | 무협맵 해당 |
|---|---|---|---|
| **1순위** | **35류** | 광고업, 광고 중개, 마케팅, 온라인 광고, **판매·중개 알선** | 체험단/협찬 **중개·광고 매칭**이 서비스 핵심 → 가장 중요 |
| 2순위 | **9류** | **다운로드 가능한 모바일 앱 소프트웨어**(상품으로서의 앱) | 앱스토어 배포 앱 보호 |
| 2순위 | **42류** | **SaaS/플랫폼 제공**, 소프트웨어 개발·호스팅, 온라인 지도 제공 | "서비스로서의 플랫폼" 보호 |

- **비용 최소로 간다면**: **35류 1개만** 먼저. (중개·광고가 사업의 본질이라 분쟁 시 가장 핵심)
- **권장(가성비)**: **35류 + 9류**(또는 42류) **2개 류**. 앱/플랫폼까지 커버.
- 류를 늘릴수록 출원료·등록료가 **류 수만큼 배수**로 붙음(아래 표).

### 비용 (2026, 전자출원·본인출원·1류·지정상품 10개 이하)
| 항목 | 금액(1류당) | 시점 | 비고 |
|---|---|---|---|
| 출원료(전자) | **52,000원** | 출원 즉시 | 지정상품 10개 초과 시 +2,000원/개 |
| (선택) 우선심사 신청료 | 160,000원 | 출원 시 | 심사 10~14개월 → 2~5개월로 단축. 급하지 않으면 생략 |
| 설정등록료(10년) | **201,000원** | **등록결정 후(≈6~14개월 뒤)** | 2회 분할 시 1회차 122,000원 |
| 등록면허세(지방세) | 9,120원 | 등록 시 | 분할납부면 1회차에 |
| **합계(등록까지)** | **약 262,000원/류** | — | 우선심사 제외·분할 안 할 때 |

- **당장 나가는 현금은 출원료만** → **35류 1개 = 5.2만원 / 35+9류 2개 = 10.4만원**. 20만원대 등록료는 **심사 통과한 뒤**에 낸다(불허되면 안 냄).
- **등록까지 총액 추정**: 1개 류 ≈ **26만원**, 2개 류 ≈ **52만원**(변리사 없이).
- **변리사 대리 시**: 류당 대리수수료 대략 **20~40만원** 추가(출원)+등록 시 추가. → 2개 류 올인 대략 100~150만원대. **직접출원이면 이 수수료 0원.**
- ⚠️ 상표는 특허와 달리 **개인 70% 감면이 적용되지 않음**(그 감면은 특허/실용신안/디자인 전용). 전자 직접출원 52,000원이 사실상 최저가.

### 로고·캐릭터는?
- 지금 쓰는 **핀 로고·캐릭터(무협 소년+시바견)** 는 **저작권은 창작 즉시 자동 발생**(등록 불필요, 분쟁 대비 한국저작권위원회 등록은 건당 수만원·선택).
- 상표로도 보호하려면 **도형상표(로고)** 를 별도 출원해야 함(문자상표 "무협맵"과 별건, 류별 비용 또 발생). **지금은 문자상표부터**, 로고 상표는 예산 여유 시 후속.

## 2. 특허 / BM특허 (지금 보류 ⏸️)

### 왜 지금은 하지 말라는가
1. **진보성(신규성) 확보가 어렵다**: "지도에 체험단/협찬을 모아 보여주고 중개"는 개념적으로 새롭지 않고 **유사 선행 서비스가 다수**(거지맵류, 각 체험단 플랫폼). 특허는 "기술적 진보성"을 요구 → **거절 가능성이 높음**.
2. **비용이 크다**: 명세서 작성이 전문영역이라 **사실상 변리사 필수**. 출원~등록 총 **200~600만원**(관납료 별도), 심사 **1.5~2년**(우선심사 시 4~6개월, 추가비용). 개인 70% 감면은 관납료에만 적용되고 **변리사 수수료(대부분)에는 안 됨**.
3. **이미 공개 운영 중 = 신규성 리스크**: 특허는 출원 전 공개되면 신규성 상실이 원칙. 본인 공개는 **"공지예외" 12개월 이내**만 구제 가능 → 오픈 시점 기준 시한 압박까지 있음.

### 예외 — 이럴 때만 검토
- 범용 지도/집계가 아니라 **진짜 독창적인 기술요소**(예: 특정 협찬-인플루언서 **자동 매칭 알고리즘**, 수집·중복제거·좌표해석의 고유 방식 등)가 있고, 그게 사업 방어의 핵심이라면 → **가출원(provisional, 저비용·명세서 간이)** 으로 **출원일만 선점**해두고 1년 내 정식출원 여부를 판단하는 정도만 고려. 그 외엔 **상표에 예산 집중**이 맞음.

## 3. 지금 실행 체크리스트 (직접 전자출원)

- [ ] **0. 선행상표 검색(필수·무료)**: [KIPRIS](http://www.kipris.or.kr)에서 "무협맵" + 유사표장을 **35/9/42류**에 동일·유사 선등록/출원 있는지 확인. (있으면 식별력/네이밍 재검토)
- [ ] 1. [특허로](https://www.patent.go.kr) 회원가입 → **출원인코드 부여신청** + 전자서명(공동인증서 등) 등록.
- [ ] 2. 상표 유형 = **문자상표 "무협맵"** (로고 상표는 후속).
- [ ] 3. **지정상품 선택**: 특허청 **고시명칭**에서 35류(광고·중개 알선) / 9류(다운로드 응용소프트웨어) [/ 42류(SaaS·온라인 지도 제공)] 상품 선택. 각 류 **10개 이하**로 잡으면 가산료 없음.
- [ ] 4. 전자출원서 제출 + **출원료 납부**(류당 52,000원). 급하면 우선심사(류당 160,000원) 추가.
- [ ] 5. 심사 대기(약 10~14개월 / 우선심사 2~5개월). **의견제출통지** 오면 대응.
- [ ] 6. **등록결정 → 2개월 내 설정등록료 납부**(201,000원/류, 또는 2회 분할).

### 예산 시나리오 요약
| 시나리오 | 당장 현금(출원) | 등록까지 총액 | 비고 |
|---|---|---|---|
| **최소** (35류 1개, 직접) | 52,000원 | 약 262,000원 | 핵심 중개만 방어 |
| **권장** (35+9류 2개, 직접) | 104,000원 | 약 524,000원 | 앱까지 커버 (가성비) |
| 급할 때 (+우선심사 2류) | +320,000원 | +320,000원 | 2~5개월로 단축 |
| 변리사 대리 (2류) | — | 약 100~150만원+ | 수수료 포함, 손 덜 감 |
