# 무협맵 서비스 비전

## 출발점 — 왜 만들었나 (Founding Insight, 2026-09-04 원우씨 명시)

무협맵을 시작하게 된 실제 계기(원우씨=리뷰어 본인의 경험):

강남맛집 체험단으로 **홍대 맛집 한 곳에 당첨**됐다. 홍대까지 원정 가는 김에 *"이왕 가는 거, 근처에 다른 협찬(카페·저녁)도 있으면 같이 해버리면 좋을 텐데"* 싶었다. 리뷰어는 협찬 하나 하러 멀리 가면 **그 근처로 한두 개 더 묶어 하루에 뛰는 게 가장 이득**이기 때문.

문제: **나는 홍대에 안 산다.** 협찬 주소만 봐서는 그게 내가 갈 맛집 근처인지 감이 안 온다. 기존 체험단 플랫폼은 전부 **리스트**라 "이 근처에 뭐 있어?"를 알 수가 없다.

→ **핵심 통찰: 지도가 리스트를 이기는 결정적 순간 = "내가 갈(당첨된) 곳 주변으로 협찬을 묶을 때"(동선 묶기·원정 최적화).** 특히 안 사는 동네일수록 주소 리스트는 무의미하고, 지도라야 "근처에 뭐가 더 있나"가 보인다. 이 경험이 무협맵의 출발점이자, 리스트형 경쟁 서비스 대비 **가장 뾰족한 차별 지점**이다. → 마케팅/포지셔닝의 1차 메시지 축으로 채택(첫 블로그 글도 이 방향).

## Mission

협찬을 찾는 시간을 줄이고, 협찬 가능한 매장의 데이터를 가장 풍부하게
제공하는 플랫폼을 만든다.

## Vision

무협맵은 캠페인 중심 서비스가 아니라 **매장 중심 서비스**를 지향한다.

## 핵심 가치

-   지도 기반 탐색
-   협찬 + 후기 + 제보의 연결
-   데이터의 지속적인 축적
-   사용자 참여 기반 성장
