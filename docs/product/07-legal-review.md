# 법률 검토 — 협찬 플랫폼 약관·개인정보처리방침 분석

> **목적**: 무협맵이 협찬 플랫폼의 캠페인 정보를 지도에 집약할 때 각 플랫폼의 **이용약관·개인정보처리방침** 상 어떤 법적 문제가 생길 수 있는지 플랫폼별로 정리한다. 대상·순서: **리뷰노트 → 강남맛집 → 디너의여왕 → 레뷰 → 미블**.
>
> **전제(현재 방향)**: 무협맵은 대량 자동수집을 보류하고 **커뮤니티(리뷰어) 제보 중심**으로 운영하며, 자동화는 저빈도·사실필드·출처링크백·사람검수의 제한적 형태로만 검토한다. 자세한 배경은 [03-platform-analysis](03-platform-analysis.md)·[10-growth-strategy](10-growth-strategy.md) 및 메모리 `project_scraping_plan` 참고.
>
> ⚠️ **면책**: 본 문서는 2026-07 기준 **공개정보·일부 실제 약관 확인·기존 프로젝트 검토**를 종합한 정리로 **법률자문이 아니다**. 약관은 수시로 바뀌므로, 실제 수집을 착수하기 전 **각 플랫폼 최신 약관 원문 + 변호사 검토**를 반드시 거친다.
>
> **확인상태 범례**: 🟢 실측(약관/정책 원문 확인) · 🟡 공개정보(검색·소개페이지) · ⚪ 추정(동종 플랫폼 관행 기반, 원문 미확인)

## 1-1. 실측 조항 상세 (원문 확인)

### ① 리뷰노트 (reviewnote.co.kr) — 🟢 이용약관·개인정보처리방침 전문 확인
- **제9조 금지행위(발췌, 원문)**
  - "회사의 동의 없이 서비스 정보를 변경하거나, **영리 또는 비영리 목적으로 정보를 복제, 출판, 방송 등에 사용하거나 제3자에게 제공하는 행위**"
  - "해킹, **매크로, 어뷰징 등 부정한 방법**으로 서비스를 이용하는 행위"
  - "회사가 게시한 정보를 무단으로 변경하는 행위" / "회사의 정보를 무단으로 사용하거나 사칭하는 행위"
  - "회사 및 제3자의 지적재산권 침해" / "타인의 미디어·콘텐츠·저작물을 무단 복제·등록·배포"
- **제13조**: 서비스에 대한 저작권·지재권 **일체 회사 귀속**. **제16조**: 회원 콘텐츠 사용권 등록일로부터 1년 회사(복제·전시·배포·2차저작권 포함). **제18조**: SNS 데이터는 회원 동의 하 **공개데이터로 한정** 수집.
- **개인정보처리방침**: 최소수집. 수집항목에 회원 PII 외 **사업자 정보(사업자등록번호)·매장 정보(매장명·매장주소)** 포함, 광고주에 회원정보 제3자 제공 → 캠페인의 매장정보도 리뷰노트가 계약으로 수집·관리하는 데이터.

### ② 레뷰 (revu.net) — 🟢 이용약관·개인정보·플랫폼이용정책 전문 확인
- **제9조 e항(리뷰노트와 사실상 동일 문구)**: "**회사의 동의 없이 서비스 정보를 변경하거나, 영리 또는 비영리 목적으로 정보를 복제, 출판, 방송 등에 사용하거나 제3자에게 제공하는 행위**" + "부정한 방법으로 콘텐츠를 게재·홍보하여 손해를 끼치는 행위".
- **제13조** 서비스 저작권 회사 귀속, **제16조** 보상 콘텐츠 사용권 회사, **제18조** SNS 공개데이터 동의수집.
- **플랫폼이용정책**: '콘텐츠' 정의에 "**회사가 복제한 게시물 포함**", 무단 수익링크·재판매 금지.
- **개인정보(레뷰코퍼레이션)**: 최소수집(이메일/네이버·애플 간편가입, 캠페인 참여 시 이름·연락처·배송지 등).

### ③ 강남맛집 (체험 주식회사) — 🟢 이용약관·개인정보처리방침 확인
- **제19조**: "체험하고 작성한 모든 형태의 리뷰는 회사와 상의 없이 임의로 삭제·변경할 수 없으며 **그 저작권은 회사에 귀속**"(미작성·임의삭제 시 상품가 변제). **제12조**: 회사가 연결정보 생성·검색 위해 콘텐츠 사본 저장.
- 상업행위(해킹·광고수익 등) 금지. **명시적 자동수집 금지 조항은 없음**(리뷰노트·레뷰 대비 약함).
- **개인정보**: 최소수집(아이디·실명·연락처·블로그주소·이메일·생년월일·성별 등 회원 PII). 매장정보 수집 항목은 없음.

### ④ 미블 (mrblog.net) — 🟢 이용약관 확인
- **제11조**: "서비스를 이용하여 얻은 정보를 회원의 개인적 이용 외에 **복사·가공·번역 등 2차적 저작을 통하여 복제·공연·방송·전시·배포·출판 등에 사용하거나 제3자에게 제공하는 행위**" 금지. **제12조**: 광고·상업행위 시 콘텐츠 삭제 사유. 회원제(만 13세↑·국내거주·개인만).

### ⑤ 디너의여왕 (dinnerqueen.net) — 🟢 이용약관·개인정보처리방침 확인
- **금지행위(원문)**: "g. **회사의 동의 없이 영리를 목적으로 서비스를 이용하는 행위**" / "c. 회사 및 기타 제3자의 저작권 등 지적재산권에 대한 침해" / "d. 명예훼손 또는 **업무를 방해하는 행위**" + "기타 회사의 업무에 방해되는 행위 금지".
- **제13조**: 서비스 저작권·지재권 일체 회사 귀속. **제16조**: 회원 콘텐츠에 대해 회사가 사용료 없는 **영구 사용권**(복제·전시·배포·편집·2차저작), 마케팅 활용.
- **개인정보**: 최소수집(로그인ID·연락처·주소·계좌·주민번호 등), 목적에 "**서비스 부정이용 방지**"·"불량 이용기록" 수집 명시.
- 리뷰노트·레뷰의 "매크로·어뷰징" 같은 자동화 명문 조항은 없으나, **g(영리목적)+지재권+업무방해+제13조 저작권**으로 커버. **robots는 일부 허용**·SSR이라 5곳 중 유일하게 제한적 수집 여지가 있는 곳.

> **핵심 결론**: 리뷰노트·레뷰는 **동일 약관 템플릿**으로 둘 다 "회사 동의 없이 서비스 정보를 영리·비영리 불문 복제·제3자 제공 금지(제9조 e)" + "매크로·부정한 방법 이용 금지" + "서비스 저작권 회사 귀속(제13조)"을 **명문화**. 무협맵이 이들 캠페인 정보를 긁어 지도에 게재하는 것은 **자동수집=부정한 방법**, **지도 게재=제3자 제공·복제**로 **정면 저촉**된다. 미블도 2차저작 전면금지(제11조). 강남맛집은 자동수집 명문 조항은 없으나 **리뷰 저작권이 회사 귀속(제19조)**이라 리뷰 본문·이미지 복제는 위험.

## 3. 공통 법적 프레임워크 (플랫폼 불문 적용)

| **정보통신망법 §48** | 정당한 접근권한 없이/허용범위 넘어 **정보통신망 침입** → 형사처벌 | **로그인 벽 우회(리뷰노트·레뷰·미블) 시 형사 리스크** — 절대 회피 |
| **형법 §314 업무방해** | 대량·고빈도 요청으로 서버 부하 유발 | 크롤링 빈도·병렬성 관리 필요 |
| **개인정보보호법** | 개인정보의 무단 수집·이용 금지 | 우리가 긁는 건 **매장 협찬 "사실"**(개인정보 아님)이 원칙. 리뷰어 개인정보는 수집하지 않음 |

### 참고 판례 (우리와 구조 유사 → 불리)

| 판례 | 쟁점 | 결과 | 시사점 |
|------|------|------|--------|
| **잡코리아 vs 사람인** | 채용공고 DB 크롤링·집계 | DB제작자 권리 침해 + 부정경쟁 **인정(수집측 패)** | "목록 긁어 집약" 구조가 그대로 패소 사례 |
| **야놀자 vs 여기어때** | 제휴점 정보 크롤링/API 접근 | **정보통신망법 위반 형사 유죄** | 접근권한 우회는 민사 아닌 **형사** |
| (참고) 네이버 성과도용류 | 데이터 무단활용 | 성과도용 흐름 인정 경향 | (파)목 리스크 방증 |

## 4. 종합 결론 & 권고

1. **기술적으로 가능 ≠ 법적으로 안전.** 집계형 서비스는 판례군이 불리(잡코리아·야놀자). "리스크 제거"가 아니라 **"리스크 관리"** 문제다.
2. **로그인 벽 플랫폼(리뷰노트·레뷰·미블)은 자동수집 대상에서 제외.** 우회 시 정보통신망법 **형사** 리스크 — 하지 않는다.
3. **저작권·2차저작 조항(강남맛집·미블 등)** 때문에 **리뷰 본문·이미지는 복제 금지**. 무협맵은 매장·협찬 **"사실 필드"만** 다루고 원문은 **출처 링크백**.
4. **디너의여왕(SSR·robots 일부 허용)** 정도만 제한적 수집 여지 — robots 준수 + 저빈도 + 사실필드 + 링크백 + 사람검수로 관리. 그래도 9조(g) 접촉은 남으므로 **장기 제휴로 해소**.
5. **최우선 전략 = 제휴/허락.** 무협맵이 신청자 트래픽을 플랫폼으로 보내주는 구조 자체가 협상 카드다. 그 전까지 데이터 원천은 **커뮤니티 제보 + (내부용) URL 단건 자동입력 검수 툴** 수준으로 한정한다.
6. **절대 하지 않는다**: 전국 협찬을 매일 대량 무단 크롤링해 무협맵 DB를 만드는 것.

### 실무 체크리스트
- [ ] 착수 전 대상 플랫폼 **최신 약관·robots.txt 원문** 재확인(변경 잦음)
- [ ] 로그인/접근권한 우회 없음(공개영역만)
- [ ] 이미지·리뷰 본문 미복제, 사실필드만 + 출처·링크백
- [ ] 저빈도·병렬 제한(업무방해 방지)
- [ ] 커뮤니티 제보 비중이 실제 다수 → 집계성 비중 최소화
- [ ] 중요 판단 전 **변호사 검토**

## 5. 무협맵 권장 운영 방식 (2026-07-23 확정 방향)

> **자동수집은 하지 않는다**(2026-07-23 결정). 경쟁사 콜라보매니저도 **제휴한 소수 플랫폼만 데이터 집계 + 나머지는 링크만** 운영하는 것이 실측으로 확인됨([11-competition](11-competition.md)) — 이 "가장 안전한 모델"이 시장에서 이미 검증되고 있다. 무협맵도 동일 원칙으로 간다.

### 데이터가 들어오는 경로 = 3단계 우선순위

| 우선 | 방식 | 리스크 | 설명 |
|------|------|--------|------|
| **1순위** | **리뷰어 제보(커뮤니티 UGC)** | 🟢 낮음 | 무협맵은 플랫폼과 계약관계·직접 크롤링 없음 → "커뮤니티 게시판" 성격. 데이터 원천의 **다수**가 여기여야 방패가 됨. |
| **2순위** | **운영자 소량·선별 직접 입력** | 🟡 중간 | 사람이 보고 골라 넣는 수준. 한 플랫폼을 조직적으로 통째 옮기지 않기. 협찬 내용은 **원문 복붙 말고 요약·재작성**, 매장·조건은 사실만. |
| **제휴 후** | **제휴 플랫폼 데이터 정식 노출** | 🟢 안전 | 동의를 받은 플랫폼은 캠페인을 당당히 집계·노출. **제휴 없는 곳은 데이터 대신 신청 링크(바로가기)만.** |

### 지켜야 할 원칙 (항상)
1. **자동 대량 크롤링 금지.** 로그인 벽 플랫폼(리뷰노트·레뷰·미블)은 특히 접근조차 안 함.
2. **협찬 "내용" 문구는 요약·재작성**, 리뷰 본문·이미지는 미복제. 매장명·주소·마감일·요일·시간 등 **사실 필드만** 그대로.
3. **원문 신청 링크백 필수** — "경쟁·대체"가 아니라 "**플랫폼으로 신청자를 보내는 유입 채널**"로 포지셔닝. 부정경쟁 주장을 약화시키고 제휴 협상 카드가 됨.
4. **한 플랫폼의 캠페인 목록을 통째로 재현하지 않기** — 개별이 사실이어도 "상당 부분 복제"는 DB권(잡코리아 판례) 리스크.
5. **커뮤니티 제보가 실제 다수**가 되도록 운영(집계성 비중 최소화) → UGC 방패 유지.
6. 규모가 커지기 전에 **디너의여왕 등과 제휴 협상**(우리가 지도로 신청자 보내주는 가치 제안). 그 전까지는 1·2순위로만.

### 한 줄 요약
> **"긁지 않는다. 리뷰어가 올리고(1순위), 운영자가 소량 선별 보완(2순위)하며, 협찬 내용은 재작성 + 신청은 원문 링크로. 데이터를 통째로 집계하려면 그 플랫폼과 제휴부터."**
