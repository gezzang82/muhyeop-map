# 협찬 제보 활성화 — 설계 메모

> 무협맵의 "협찬 제보하기"를 어떻게 활성화할지에 대한 논의 정리. (구현 전 방향성 메모)

## 1. 문제 정의: UI가 아니라 "동기" 문제
- 리뷰어/인플루언서에게 협찬은 **경쟁 자원**. 내가 찾은 협찬을 제보하면 = **경쟁자에게 떠먹여주는 손해**.
- 그래서 단순 장치로는 동기가 안 생김:
  - **최초제보자/제보자 표시(명예)** → 명예 보상 < 경쟁 디스인센티브. 오히려 "내가 이 협찬 노린다"를 드러내는 역효과.
  - **오픈 커피쿠폰 이벤트** → 일회성 스파이크 후 절벽 + 쿠폰 노린 저품질/가짜 제보(어뷰징)만 쌓임.

## 2. 핵심 통찰: 블로거가 원하는 보상은 "조회수(유입)"
- 블로거의 진짜 화폐 = **투데이 조회수/트래픽**.
- 협찬을 공유해서 손해 보는 대신 **내 블로그로 유입을 돌려받으면 그게 더 이득** → 경쟁 디스인센티브 상쇄.
- 설계 원칙: **무협맵을 트래픽 허브로 만들고, 기여한 만큼 트래픽을 블로거에게 분배** (제보/후기 → 노출 → 조회수).

## 3. 함정: 제보자 ≠ 그 협찬을 한 사람
- 맵에 올라온 협찬 대부분은 "발견해서 올린 것"이지 **본인이 체험한 게 아님**.
- 따라서 "그 협찬의 후기로 유입"은 대다수 케이스에 안 맞음(후기가 없음).
- 제보 시점엔 보통 아직 체험 전 → 후기는 체험 *후*에 생김.

## 4. 해결: "제보(발견)"와 "후기(트래픽 엔진)"를 분리
```
공급(협찬 목록)   = 어드민 시딩 + 제보(발견)      ← 본인이 안 해도 OK
유입(트래픽 분배) = 그 체험단을 실제 한 블로거가
                   자기 후기 링크를 그 협찬에 붙임  ← 조회수 보상 엔진
```
- 매장/협찬 상세에 **"이 체험단 후기"** 영역 → 다녀온 블로거들이 자기 후기 링크 등록.
- 협찬 보러 온 사람: "이거 실제 어땠지?" → **후기 클릭 → 그 블로거에게 유입** (클릭 의도 강함).
- 후기 많이/잘 붙일수록 **노출 가중치 ↑ = 노력 비례 조회수**.
- 후기 공유엔 **경쟁 디스인센티브 없음**(이미 공개된 글, 링크 = 순수 유입 이득).

## 5. 어뷰징 리스크와 방어 (관련 없는 글 붙여 클릭 빼가기)
가장 큰 리스크. 여러 겹으로 방어:
1. **자동 검증(1차, 싸고 효과 큼)**: 후기 URL 등록 시 서버에서 글을 읽어 **매장명/주소 키워드 포함 여부 자동 체크**. 무관한 글 1차 차단.
2. **품질 연동 보상(구조적 차단)**: 보상을 "클릭"이 아니라 **도움돼요 수·체류** 같은 품질 신호에 연동 + 도움돼요순 정렬 → 어뷰징 유인 자체를 제거.
3. **커뮤니티 신고**: "협찬과 관련 없음" 신고 → 임계치 넘으면 자동 숨김 (기존 신고 시스템 재활용).
4. **어드민 검수 / 레이트리밋**: 초기엔 어드민 승인 후 노출. 1매장 1인 1후기, 일일 한도, 신규 계정 제한.
- 초기 현실 조합: **1차(자동검증) + 3차(신고) + 4차(1인1후기·검수)**. 양 늘면 2차(품질 가중치) 추가.

## 6. 전제 & 순서 (플라이휠)
- 유입은 **무협맵 자체 트래픽에 비례** → 나눠줄 트래픽이 있어야 보상이 성립.
- 그래서 순서: **공급 시딩(공개 체험단 집계) → 트래픽 → 기여자에게 유입 분배 → 더 많은 제보/후기 → 풍부한 맵 → 트래픽 ↑**.
- 공개 체험단 정보(레뷰·디너의여왕 등)는 대부분 공개 정보 → 어드민/크롤링 시딩으로 맵을 먼저 "살아있게".

## 7. 보조 아이디어
- **공급자(사장님/업체) 제보 채널**: 사장님은 리뷰어 유입을 원하므로 **디스인센티브 없이 등록 동기 있음**. "매장 협찬 무료 등록 → 리뷰어가 찾아옴"(공짜 홍보).
- **리뷰어 제보는 "내가 안 할 협찬"**(지역·카테고리 안 맞는 것)만 가볍게 유도 → 경쟁 안 되는 것만 공유.

## 구현 시 손댈 영역 (참고)
- 매장/협찬 상세에 **"이 체험단 후기" 리스트 + 후기 등록 폼**.
- DB: 후기 링크/작성자/도움돼요 등 (`campaigns` 확장 또는 별도 테이블).
- 후기 URL **자동 키워드 검증** 로직(서버사이드 fetch + 매장명 매칭).
- 노출 **가중치/정렬** 로직(도움돼요·품질 기반).
